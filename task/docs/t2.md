## nbconvert
Инструмент для преобразования `.ipynb` файлов в различные статические форматы
### Реализация

Ход:
1. Получение данных
2. Исполнение notebook путем инструмента nbconvert
3. Пример: `jupyter nbconvert --to markdown <ПУТЬ_СОХРАНЕНИЯ>`

### Результат
